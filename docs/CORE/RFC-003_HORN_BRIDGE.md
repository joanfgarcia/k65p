# RFC-003: The Horn Bridge — K-65P ↔ Prolog

> **Status**: ACTIVE (v0 subset) — reference implementation in `src/k65p/bridge.py`
> **Authors**: Joan Garcia + Aleth (Claude Fable 5), 2026-07-16
> **Scope**: ground (variable-free) K-65P v0. Variables and the `RULE` functor arrive with
> K-65P v1 (RFC-002 §5) and will extend this mapping to proper Horn clauses.
> **Source of truth**: on any discrepancy, `bridge.py` wins and this document gets fixed.

---

## 1. Why a bridge

K-65P makes thought *representable*; Prolog makes it *checkable*. The bridge is the
contract between the two: every valid K-65P v0 clause crosses to exactly one ground Prolog
clause, and every bridge-generated Prolog clause crosses back to the identical canonical
tree. **The bridge refuses invalid K-65P** — translation presupposes certification.

## 2. The mapping (v0)

| K-65P construct | Prolog | Note |
|---|---|---|
| Fact `[60 fuego]` | `hot(fuego).` | evaluator → unary functor |
| Predicate `[24 2 fuego]` | `touch(someone,fuego)` | valency frame → n-ary functor, args positional |
| Group `[G 4 9]` | `g(something,[bad])` | head + modifier list |
| Unary `[44 C]` | `neg(C')` | `NOT` escapes to `neg` (`not` is reserved) |
| `[45 C]` / `[46 C]` | `maybe(C')` / `can(C')` | modality wraps the term |
| Spatio-temporal `[31 C]` … | `before(C')` … | frames wrap the term |
| Binary `[47 A B]` / `[51 A B]` | `because(A',B')` / `like(A',B')` | foreground first |
| Conditional `[48 A B]` — representation | `implies(A',B').` | canonical, round-trip guaranteed |
| Conditional `[48 A B]` — executable | `B' :- A'.` | ground rule: the engine can chain it |

**Atom naming**: operator primes → english symbol lowercased (collision-escaped:
`NOT→neg`, `IF→implies`); argument-position primes → english symbol lowercased with
reserved escapes (`TRUE→truth`, `NOT→not_`); molecules → their lexicon name, quoted when
not a plain Prolog atom (`'árbol'`). Reserved names (`truth`, `not_`, the 37 functors) are
forbidden as molecule names — enforced by the lexicon integrity suite (RFC-004).

## 3. Examples (generated by the bridge — never hand-written)

```
K-65P:  [caliente fuego]
repr:   hot(fuego).
back:   [60 fuego]

K-65P:  [si [tocar alguien fuego] [pasar [G algo malo] alguien]]
repr:   implies(touch(someone,fuego),happen(g(something,[bad]),someone)).
exec:   happen(g(something,[bad]),someone) :- touch(someone,fuego).
back:   [48 [24 2 fuego] [22 [G 4 9] 2]]

K-65P:  [querer yo [decir tú verdad yo]]
repr:   want(i,say(you,truth,i)).
back:   [14 0 [18 1 20 0]]

K-65P:  [no [ver yo algo]]
repr:   neg(see(i,something)).
back:   [44 [16 0 4]]
```

## 4. Guarantees and refusals

1. **Round-trip**: `from_prolog(to_prolog(x)) == linearize(x)` for every valid v0 clause —
   property-tested over the full RFC-002 seed corpus (`k65p.examples`).
2. **No smuggling**: `to_prolog` raises on invalid K-65P; `from_prolog` raises on foreign
   functors, bare atoms, and well-formed Prolog that would decode into invalid K-65P
   (`die(i,you)` is a Prolog term but never a K-65P thought).
3. **Executable form** is one-way sugar for the engine: only top-level conditionals split
   into `head :- body`; `from_prolog` reassembles them.

## 5. Verification semantics (consumed by Phase 2)

A knowledge base is a set of ground facts plus ground `implies/2` clauses loaded in
executable form. `verify(expr)`:

- **fact** → provable from the KB (direct membership or chaining through ground rules);
- **conditional** → its executable form is consistent with the KB (and reported as an
  assumption if novel);
- verdicts carry the **proof tree** (`--explain`): the derivation on success, the exact
  failing premise on failure — the right to review is part of the contract, not a favor.

## 6. Hume's guillotine, encoded

`WANT`/`FEEL` clauses (`want(i, X)`, `feel(i, bad)`) translate and store like any term, but
the KB layer treats them as **volitional state, not world facts**: they can be *recorded*
and *queried*, never *refuted* by physical facts. The verifier audits reasoning; it is
constitutively unable to dictate values. (Doctrine of conscience — ROADMAP Phase 5.)
